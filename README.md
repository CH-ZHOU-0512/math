# 我的数学 AI 工具箱

当前版本：0.3.0。

用五个技能支持未知数学领域的学习：先建立概念图景，再攻坚难点、保留学习过程，最后把真正属于自己的理解写下来。

| 技能 | 职责 |
| --- | --- |
| teacher | 带学概念、补基础、制作初学讲义 |
| coach | 难题、困难概念与论证的研究攻坚 |
| registrar | 整理自动笔记、讲义库和题库 |
| write | 人与 AI 共同表达、检验自己的理解和感悟 |
| administrator | 检索、修改和维护已有资料 |

学习流程：**teacher → coach → registrar → write**，administrator 全程按需参与。各阶段可往返，不会因为调用一个技能而自动执行所有阶段。

## 两种研究模式

coach 的提示模式允许逐层提示；引导模式严格禁止提示，默认零公式输出，只检查用户已经表达的论证，不以提问、图像、代码或其他技能泄露新方向。

```text
$coach 提示模式，沿我的思路推进，每次只给一层提示。
$coach 引导模式，严格不提示、零公式输出，只检查我的现有论证。
```

这些是技能指令，不是程序级输出拦截器；真实行为需要持续验证。

## 两类笔记

自动笔记由 registrar 整理，可以包含知识、证明和学习过程；自写笔记由 write 与用户共同写，只表达用户自己的理解、感悟及其理由。AI 新增而尚未被用户吸收的证明或建议不进入自写笔记。两类通过目录和来源属性区分，可以关联，不直接合并。

```text
$teacher 带我初步了解这个领域，再制作一份初学讲义。
$registrar 把刚才学过的内容整理为自动笔记，保留真实尝试和提示来源。
$write 从我刚才的理解出发共同写作，检查理由和边界，不替我发明感悟。
$administrator 查找我关于这个主题的自写笔记，给出具体出处。
```

标题、文件名和目录名使用可读主题；编号、ID、原题号分别保留在属性或正文来源中。

## 安装与检查

需要 Python 3.10 或更新版本。克隆或下载本仓库后，在仓库根目录运行：

```powershell
python -m pip install -r requirements.txt
python -X utf8 maintenance/manage.py check
python -X utf8 maintenance/test_manage.py
python -X utf8 maintenance/manage.py deploy
```

默认安装到用户目录下的 `.codex/skills`，也可以用 `--target` 指定技能目录。首次安装只接受空目标或与源码完全一致的既有五技能内容；发现不同的已安装内容会停止，先比较和合并，不直接覆盖。本工具只管理表中五个技能，不触碰目标目录内的其他技能。

本机安装状态与部署备份不进入 Git。部署会生成本机状态并保存可恢复副本；之后可用 `status` 比较源码与安装版，用 `restore --backup 实际备份路径` 回退。复制不是多文件事务，中途失败需按备份清单核查。

首次实际归档或检索时提供学习库位置。本仓库不包含个人学习笔记、实际库路径或聊天记录，也不会自动迁移已有学习库。
