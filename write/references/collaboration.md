# 工具箱协作约定

## 未知数学领域的学习流程

learn 带学概念并制作初学讲义，先建立整体图景；think 对困难概念、难题与论证做研究性攻坚；log 把实际过程整理为自动笔记、讲义库和题库；理解逐渐深入后，write 与用户把自己的理解、感悟和尝试写成自写笔记，并论证其合理性。manage 在各阶段按需检索、修改与维护资料。

这是用户选择的工作流程，不是调用一个技能就自动执行全部阶段。用户已要求组合动作时连续完成，不重复索要许可或强制换聊天。研究、自动归档与个人写作可以往返，不以固定测试成绩作为进入 write 的门槛。

## 职责与边界

| 动作 | 技能 | 边界 |
| --- | --- | --- |
| 初学、补基础、初学讲义 | learn | 深究难点转 think，讲义完成不等于已学 |
| 难题、困难概念、论证攻坚 | think | 提示模式可分层提示；引导模式禁止提示、默认零公式 |
| 自动整理学习过程、讲义和题目 | log | 知识笔记属于自动笔记，不代写个人思想 |
| 共同表达并论证自己的理解 | write | 自写笔记，不把 AI 新加内容冒充个人洞察 |
| 检索与维护已有资料 | manage | 查找不附带开课或写回，保留笔记来源 |

每轮先判断任务职责并实际遵循适用技能；进入新职责时读取对应 SKILL.md，参考资料按需读取。已读且未变化的规则持续适用，不每轮机械重读，也不把五个技能全部套用。

技能交接表示应用下一职责的规则，不表示已调用另一个代理；没有实际读取、写入或发送就不能宣称完成。其他技能不可用时说明实际限制，在原任务和工具能力内继续。

## 保留上下文

按需保留目标与范围、完整题干或实际文件及版本、用户原话与路线、已完成步骤、卡点、提示来自谁、未完成事项和证据来源。写入时另保留目标库、条目 ID、新建还是修改及受影响文件。不要求重述仍可见的信息。

think 的当前模式及公式限制属于必要交接信息。learn、write、检索或复盘不能成为绕过严格引导的途径；用户明确要求提供提示或完整解答才改变相应边界。引用旧材料会泄露当前问题的解法时也须遵守限制。

其他聊天只有实际可读且在授权范围内才可作为依据；否则只要必要摘要。无归档授权时交接信息留在对话中；当前请求或已有持续授权覆盖时，按下述归档规则保存必要过程。

## 自动笔记与自写笔记

log 的新笔记放“自动笔记”，note_origin 为 automatic。write 的笔记放“自写笔记”，note_origin 为 self_written，另用 author_status 区分草稿和作者已确认。两类可链接但不直接合并，也不凭一次改标签就改变作者归属。

自动笔记可包含标准知识和 AI 整理；自写笔记主体只保留用户表达或认领的理解、感悟及其理由，必要背景最小化，AI 核验标明来源；尚未吸收的证明与建议留在对话或按当前请求、已有持续授权存入关联自动笔记，不混入自写笔记。历史“知识笔记”缺来源时先待确认，不按第一人称猜成自写，不自动搬迁旧库。

新条目遇到同题时查原文；自动与自写属于不同创作类型，不判作重复。真正同类同条目复用 ID；已要求更新时按 manage 规则备份维护，不互相退回。

## 命名与证据

标题、文件名、目录名用清楚的中文主题，不添加序号、题号、日期编号、ID。ID 留属性，原题号和单元位置留正文来源；数学意义的数字不删。名称冲突用主题差异词解决，不添加流水号。

学完自述、能力自述、提示下完成、独立作答、数学核验、作者认领分别记录。仅说“我能独立做”不覆盖 guided 或 explained；明确报告某次无提示完整完成时可据报告记录，并注明来源、保留历史。作者认领不等于数学证明正确。

## 持续授权与归档时机

用户已授权持续学习时主动归档的，在小节结束、切换主题或重要纠错时同步本次相关笔记、题目和学习导航；不等待再次提醒，不要求用户重答，不在每个简短答复后创建冗余记录。新条目用 log，已有条目用 manage 备份维护；详细过程留在对应条目，导航只保留简短状态和真实链接，不复制证明。仅保存过程不解除 think 的提示边界，也不代替 write 的作者认领。

尚无归档授权时不写回；归档授权也不自动授权新增提醒、定时任务或扩大跨会话读取范围。明确要求的组合任务连续完成，不重复索要批准。
